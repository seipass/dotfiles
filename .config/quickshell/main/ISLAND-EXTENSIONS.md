# 上バーのカスタム表示

設定の「上バーの表示」から、ローカルの QML ファイルを選択できます。
表示できるコンポーネントは一度に一つです。音楽表示への復帰や非表示も同じ画面から選べます。

ルートは `Item` とし、利用可能な領域は幅 165・高さ 32 の論理ピクセルです。
任意で `property var player` を定義すると、現在の MPRIS プレーヤー
（存在しない場合は `null`）が渡されます。組み込みの `IslandMusic.qml` が例です。

QML はシェルと同じ権限で実行され、サンドボックス化されません。
信頼できるファイルだけを読み込んでください。変更の自動検出、
複数拡張の登録・並べ替え、配布元からのインストール機能はありません。
